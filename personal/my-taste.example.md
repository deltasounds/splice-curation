# My taste (private — do not commit the filled-in version)

This is your private layer. Copy it to `my-taste.md`, fill it in, and keep it out of
the public repo (it's gitignored). The public repo ships the engine; your ears stay
yours.

> **Rather not write this by hand?** Load the engine into your project, then start a chat
> and say *"set me up"*. It interviews you (about nine questions) and drafts this file
> for you. You review it, then add it to the project's knowledge.

Start small. A signature or two and two to five profiles is plenty for a first session;
calibration grows the rest.

```
Last refreshed: <date> — <what changed>
```

## Account

```
Credits remaining: ____     Renewal / cancellation / pause date: __________
```

Sessions get paced against this: enough time to curate well, not so little that it
becomes a panic dump.

## Global disqualifiers (the anti-library)

What should *never* get bought, whatever the search. Start with what your own gear
already makes. You can't buy someone else's drummer twice, but you can make another
synth loop yourself.

```
My gear / instruments / plugins: ...
Never buy:
- ...
- ...
```

## Credit / effort split

Where to spend credits and attention. This is a priority guide, not a file-count target.
Put the profile numbers that feed each share in brackets so you can see which ones have
real budget.

```
__%  <category>   (profiles …)
__%  <category>   (profiles …)
```

## My signatures

Name the vibes you actually chase. For each, say what it includes *and* what
disqualifies it. Artist references are fine here — this file is private.

```
Signature:     (your name for it)
Includes:      ...
Disqualifiers: ...
Reference:     (artists / tracks that capture it — private)
```

## My profiles

Your filled-in profiles, in the format from `framework/profile-format.md`. One per gap
you most want to fill.

## Calibration log

A running scratchpad of session verdicts before they get folded into profiles:

```
Date | Profile | Verdict (yes/no/maybe) | Why
```

When a "why" recurs, promote it into the profile's Includes or Disqualifiers.
