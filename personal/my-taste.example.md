# My taste (private — do not commit the filled-in version)

This is your private layer. Copy it to `my-taste.md`, fill it in, and keep it out of
the public repo (it's gitignored). The public repo ships the engine; your ears stay
yours.

## Renewal date

```
Subscription renews / cancellation deadline: __________
```

Put this here so sessions can be paced against the deadline — enough time to curate
well, not so little that it becomes a panic dump.

## My signatures

Name the vibes you actually chase. For each, say what it includes *and* what
disqualifies it. Artist references are fine here — this file is private.

Example scaffold:

```
Signature:     (your name for it)
Includes:      ...
Disqualifiers: ...
Reference:     (artists / tracks that capture it — private)
```

## My profiles

Your filled-in profiles, in the format from `framework/profile-format.md`. Start with
two or three; let calibration grow them.

## Calibration log

A running scratchpad of session verdicts before they get folded into profiles:

```
Date | Profile | Verdict (yes/no/maybe) | Why
```

When a "why" recurs, promote it into the profile's Includes or Disqualifiers.
